# Fate Cards — Судьба решает

Отдельный мод для Fabric (Minecraft 1.21.11). Два (или больше) друга проходят
обычный мир Minecraft, а каждые 5 минут (настраивается) судьба спрашивает
каждого: «Что достанется соседу?» — и даёт выбрать одну из двух случайных
карт. Карты не «хорошая/плохая» парами — это просто две случайные карты из
общего пула почти на 90 эффектов (баффы, дебаффы, смена рельефа, мобы,
телепорты, странности и редкий легендарный хаос).

## Как играть

1. Нужно минимум 2 игрока онлайн (настраивается, `/fatecards minplayers <N>`).
2. Любой игрок жмёт **N** → «Начать режим» (или `/fatecards start`).
3. Через 15 секунд и затем каждые 5 минут (`/fatecards interval <секунды>`)
   наверху экрана у каждого игрока появляется баннер с двумя картами и целью
   («Что достанется игроку X?»). Выбор — клавишами **,** и **.** (запятая и
   точка, можно переназначить в Настройки → Управление). Не успел выбрать за
   20 секунд — выбор сделает судьба сама.
4. Эффект применяется не к вам, а к тому, кого вам назначила судьба в этом
   раунде (для двоих игроков — это всегда друг). Каждый раунд партнёры
   перемешиваются заново (для 3+ игроков — по кругу).

## Команды

| Команда | Действие |
|---|---|
| `/fatecards start` | Запустить режим |
| `/fatecards stop` | Остановить режим |
| `/fatecards status` | Текущее состояние |
| `/fatecards minplayers <N>` | Минимум игроков для старта |
| `/fatecards interval <секунды>` | Интервал между раундами (по умолчанию 300) |

## О наборе карт

В основе — присланный список из 100 карт. Реализовано около 90 из них,
честно и надёжно. Несколько карт, которые нельзя реализовать без взлома
клиента или подставных игроков, заменены близкими по духу и стабильными
аналогами (отмечено комментариями прямо в коде, `CardRegistry.java`):

- «Всё наоборот» (переворот управления) → «Головокружение» (эффект тошноты).
- «Копия» (двойник-призрак, повторяющий движения) → «Наблюдатель» (жуткая
  фигура рядом).
- «Поменять мир местами» (обмен областей карты) — пропущена как слишком
  рискованная операция (риск повреждения мира).

Карт-телепортов в биомы 16 штук, включая Бледный сад и Мрачные недра
(биом Вардена), грибные поля, вишнёвую рощу, джунгли, пустыню, ледяные
пики, бесплодные земли и несколько биомов Нижнего мира.

Также добавлена карта **«Пик высоты»** — переносит на самую высокую точку
в ближайших ~6 чанках; если поблизости есть непрогруженные чанки, игра
сама их подгрузит при поиске точки (как и обычная телепортация в игре).

Также добавлены три карты по вашей отдельной просьбе: **12 эндер-жемчугов**,
**мешок случайных предметов** и **«Земляная беда»** (весь инвентарь
заполняется землёй — легендарное наказание, выпадает редко).

## Как собрать готовый .jar

### Вариант A — автоматически на GitHub
После пуша в ветку `.github/workflows/build-fatecards-mod.yml` сам всё
соберёт на серверах GitHub и закоммитит готовый `dist/fatecards-mod.jar`
обратно в репозиторий.

### Вариант B — локально (нужна Java 21)
```bash
cd fatecards-mod
./gradlew build
```
Готовый файл — `build/libs/fatecards-1.0.0.jar`.

## Установка

1. Fabric Loader для Minecraft 1.21.11 + **Fabric API**.
2. Положите `fatecards-mod.jar` в `mods` (мод можно ставить вместе с
   Speedhunt — они независимы и не конфликтуют).
3. `/fatecards start` вдвоём (или больше) в мире.
