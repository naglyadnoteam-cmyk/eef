# Speedhunt — Спидраннер против Охотника

Мод для Fabric (Minecraft 1.21.1) в жанре Manhunt: один игрок — Спидраннер,
остальные — Охотники. Роли выдаются случайно, в правом нижнем углу экрана
появляется окошко со статусом матча.

## Правила

1. Оператор сервера запускает матч командой `/speedhunt start` (нужно минимум
   2 игрока онлайн — настраивается).
2. Роли выбираются случайно (1 Спидраннер, остальные — Охотники), но **не
   показываются сразу** — 3 секунды интриги.
3. После показа роли ещё 5 секунд действует «неприкосновенность»: Охотники
   физически не могут ударить Спидраннера.
4. Дальше — погоня. Спидраннер должен пройти игру и убить Дракона Края, не
   умерев ни разу. Спидраннер может убивать Охотников сколько угодно —
   они просто возрождаются. Если Охотник убивает Спидраннера (или тот выходит
   с сервера) — Охотники побеждают.
5. После победы любой из сторон матч автоматически сбрасывается в лобби
   (по умолчанию через 10 секунд), можно запускать заново.

### Бонусные фишки
- **Компас на соперника:** в меню (клавиша N) кнопка «Получить компас на
  соперника» — Спидраннер получает компас, указывающий на (ближайшего)
  Охотника, Охотник — компас, указывающий на Спидраннера. Направление
  обновляется сервером каждые полсекунды, пока матч идёт.
- **Периодический трекер:** раз в N секунд (по умолчанию 45) Спидраннер
  ненадолго «засвечивается» (эффект Свечения), и Охотники видят в HUD
  стрелку-направление и расстояние до него.
- **Предупреждения вверху экрана:** когда Спидраннер входит в Нижний мир
  или Энд (или возвращается в Верхний мир), у всех игроков на несколько
  секунд появляется баннер сверху экрана.
- **Редактор стартового лута:** в меню — кнопки «Изменить лут: Спидраннер /
  Охотник», открывающие экран выбора предметов (как в творческом режиме) —
  до 9 предметов на роль, с поиском. Работает только пока матч не начат.
- Красивое HUD-окошко в правом нижнем углу: роль, таймер, отсчёты.
- Клиентское меню (клавиша **N** по умолчанию, можно переназначить в
  Настройки → Управление) — старт/стоп матча, компас, редактор лута,
  включение/выключение HUD и трекера у себя.

## Как начать матч

Команды доступны **любому игроку** (не только оператору) — специально для
игры вдвоём с другом в обычном мире, включая Open to LAN без читов:

| Команда              | Действие                          |
|-----------------------|------------------------------------|
| `/speedhunt start`    | Запустить матч                     |
| `/speedhunt stop`     | Остановить и сбросить матч         |
| `/speedhunt status`   | Показать текущее состояние         |

Либо нажмите клавишу **N** (открывает меню Speedhunt) и кнопку
**«Начать матч»** — то же самое, без ввода команды.

## Настройки

Игровые настройки лежат в `config/speedhunt.json` (создаётся автоматически
при первом запуске сервера) — можно редактировать вручную и перезапустить
сервер:

```json
{
  "minPlayers": 2,
  "roleRevealDelaySeconds": 3,
  "graceProtectionSeconds": 5,
  "autoRestartDelaySeconds": 10,
  "teleportHunterOnRespawn": false,
  "trackerEnabled": true,
  "trackerIntervalSeconds": 45,
  "trackerDurationSeconds": 6,
  "hunterBonusEnabled": true,
  "hunterBonusGoldenApples": 1,
  "hunterBonusIronIngots": 8,
  "hunterBonusArrows": 16,
  "speedrunnerBonusEnabled": true,
  "speedrunnerBonusGoldenApples": 1,
  "speedrunnerBonusEnderPearls": 2
}
```

Клиентские (косметические, только для себя) настройки — `config/speedhunt_client.json`,
удобнее менять через игровое меню (клавиша N).

## Как собрать готовый .jar

### Вариант A — автоматически на GitHub (ничего не ставить на компьютер)
В репозитории настроен workflow `.github/workflows/build-speedhunt-mod.yml`.
После пуша в ветку он сам соберётся на серверах GitHub. Готовый файл будет
доступен во вкладке **Actions** → последний запуск → раздел **Artifacts**.

### Вариант B — локально (если есть Java 21)
```bash
cd speedhunt-mod
./gradlew build
```
Готовый файл появится в `build/libs/speedhunt-1.0.0.jar` — его нужно
положить в папку `mods` (Fabric Loader + Fabric API должны быть установлены
на Minecraft 1.21.1). Требуется Java 21.

## Установка

1. Установите Fabric Loader для Minecraft 1.21.1.
2. Скачайте **Fabric API** и положите в `mods`.
3. Положите `speedhunt-1.0.0.jar` туда же, в `mods`.
4. На сервере (или в мире с локальной сетью, 2+ игрока): `/speedhunt start`.
